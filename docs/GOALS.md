# SMART ゴール（ハンズオン完了条件）

SMART = Specific / Measurable / Achievable / Relevant / Time-bound

ハンズオンの「成功」は感想ではなく、**下記の完了定義を満たしたか**で判定する。

---

## 共通ゴール（社内・社外どちらでも）

### WHAT（参加者）

> **ハンズオン終了時（当日セッション内）までに**、RHADS の中核 3 製品（RHDH / RHTAS / RHTPA）の役割を各 1 文で説明でき、RHDH 上で **Software Template または Catalog の確認を 1 回以上完了**し、学びを **3 行以上のメモ（個人メモ可）** に残す。

| SMART | 内容 |
|-------|------|
| S | 製品役割の説明 + ポータル操作 + メモ |
| M | 説明できること、操作 1 回以上、メモ 3 行以上 |
| A | 90〜120 分アジェンダ内で達成可能 |
| R | RHADS / RHDH 理解という本ハンズオンの目的に直結 |
| T | 当日セッション終了まで |

### 完了チェック（参加者）

- [ ] RHDH / RHTAS / RHTPA を各 1 文で説明した（ペアまたはファシリに言える）
- [ ] RHDH にログインし、Catalog または Templates を確認した
- [ ] 学びメモを 3 行以上残した

---

## 社内向けゴール（主催・ファシリ / コミュニティ）

社内での認知向上とコミュニティ盛り上げを意図する場合に使う。

### WHAT（主催側）

> **開催日を含む 2 週間以内に**、本資料を用いた社内ハンズオン（または勉強会）を **1 回以上実施**し、参加者から **フィードバックを 3 件以上収集**して本リポジトリまたは社内スペースに反映方針を残す。開催案内には本リポジトリへのリンクを掲載する。

| SMART | 内容 |
|-------|------|
| S | 勉強会実施 + フィードバック収集 + リンク公開 |
| M | 実施 1 回以上、FB 3 件以上、案内にリポジトリ URL |
| A | 既存検証の延長と簡易アジェンダで実施可能 |
| R | Collaboration & Give Back / 社内認知・コミュニティ |
| T | 開催日を含む 2 週間以内（案内・実施・FB 収集） |

### 完了チェック（主催側・社内）

- [ ] 勉強会 / ハンズオンを 1 回開催した（日時・参加者数を記録）
- [ ] フィードバックを 3 件以上収集した（フォーム・チャット・議事録いずれか）
- [ ] 案内または社内スペースに本リポジトリ（または docs）へのリンクを掲載した

### HOW（社内・例）

- 検証済み手順を本リポジトリのアジェンダに落とす
- 社内チャンネルで開催案内を出し、リポジトリリンクを載せる
- 終了後 5 分でフィードバック（良かった点 / 改善点 / 次に試したいこと）を取る
- 改善候補を Issue またはメモに 1 件以上残す

---

## 社外向けゴール（顧客・パートナーワークショップ）

### WHAT（参加者・社外）

> **ワークショップ終了時までに**、自組織への適用観点で **「最初に試す黄金経路（テンプレートまたはパイプライン）を 1 つ**」と **「持ち帰り確認項目を 3 つ**」を書き出し、ファシリまたは自チームに共有する。

| SMART | 内容 |
|-------|------|
| S | 黄金経路 1 つ + 持ち帰り項目 3 つ |
| M | 文書またはチャットで共有された成果物がある |
| A | ハンズオン Lab の範囲で選定可能 |
| R | 導入検討・PoC の次アクションに直結 |
| T | ワークショップ終了時まで |

### 完了チェック（社外）

- [ ] 最初に試す黄金経路を 1 つ決めた
- [ ] 持ち帰り確認項目を 3 つ書いた
- [ ] チームまたはファシリに共有した

### 注意（社外）

- 実クラスタの URL・トークン・顧客固有構成は成果物に書かない
- 公開資料には一般化した表現のみ残す

---

## ファシリテータ用・セッション成功の定義

次をすべて満たせば「その回のハンズオンは成功」とする。

1. アジェンダどおり **オープニングで完了条件を共有**した  
2. 参加者の **70% 以上**が共通ゴールのチェックを自己申告で満たした（小規模なら人数で換算）  
3. 終了時に **次アクションが 1 つ以上**言語化された（社内: 再開催 or 深掘り、社外: PoC / 検証項目）
